# Moduł 3 — Zespoły i kanały

Tworzenie struktury organizacyjnej w Teams: zespoły, kanały i zarządzanie członkami.

## Tworzenie zespołu

1. **Kliknij „Zespoły” w pasku bocznym** — następnie wybierz przycisk **Dołącz do zespołu lub utwórz nowy**.
2. **Wybierz rodzaj zespołu** — firma, szkoła, inne — różne szablony dostosowane do celu.
3. **Nadaj nazwę i opis** — użyj konkretnych nazw, np. „Projekt X — marketing” zamiast ogólnych nazw jak „Zespół 1”.
4. **Zaproś członków** — wpisz adresy e-mail lub nazwy użytkowników z organizacji.

## Kanały publiczne i prywatne

Przykładowa struktura kanałów dla zespołu „Projekt Alfa”:

| Kanał | Typ |
|---|---|
| # Ogólny | publiczny |
| # Ogłoszenia | publiczny |
| # Rozwój produktu | publiczny |
| 🔒 Kadra zarządzająca | prywatny |
| 🔒 Budżet i finanse | prywatny |

**Kanał publiczny**
: Widoczny dla wszystkich członków zespołu. Idealny dla ogłoszeń i ogólnej komunikacji.

**Kanał prywatny**
: Dostęp tylko dla wybranych osób. Używaj dla wrażliwych tematów lub podgrup.

## Zarządzanie członkami

=== "Właściciel"

    - Dodaje i usuwa członków
    - Zarządza ustawieniami
    - Modyfikuje kanały

=== "Członek"

    - Wysyła wiadomości
    - Uczestniczy w spotkaniach
    - Edytuje dokumenty
