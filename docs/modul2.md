# Moduł 2 — Zakładanie i konfiguracja konta

Logowanie, instalacja aplikacji i ustawienie profilu użytkownika.

## Logowanie

1. **Otwórz przeglądarkę** — przejdź na stronę `teams.microsoft.com` lub otwórz aplikację Teams.
2. **Wprowadź adres e-mail** — użyj służbowego lub uczelnianego konta Microsoft (np. `imie@firma.pl`).
3. **Podaj hasło** — jeśli konto ma MFA włączone, potwierdź logowanie w aplikacji Microsoft Authenticator.

## Instalacja aplikacji

=== "Windows / Mac"

    - Pobierz z `teams.microsoft.com`
    - Uruchom instalator
    - Zaloguj się przy pierwszym uruchomieniu

=== "iOS / Android"

    - Wyszukaj „Microsoft Teams” w sklepie
    - Zainstaluj i otwórz
    - Zaloguj się kontem służbowym

## Ustawienia profilu

Kliknij swoje inicjały lub zdjęcie w prawym górnym rogu → **Edytuj profil**.

| Ustawienie | Opis |
|---|---|
| **Zdjęcie profilowe** | Dodaj profesjonalne zdjęcie — ułatwia identyfikację w dużych zespołach |
| **Powiadomienia** | Ustaw priorytety powiadomień, aby nie być zasypywanym wiadomościami |
| **Strefa czasowa** | Ważna przy planowaniu spotkań z osobami z innych stref czasowych |
| **Język interfejsu** | Zmień język w Ustawienia → Ogólne → Język |

!!! Uwaga: 
    Nie używaj prywatnego konta Microsoft do pracy. Zawsze loguj się kontem służbowym lub uczelnianym.
